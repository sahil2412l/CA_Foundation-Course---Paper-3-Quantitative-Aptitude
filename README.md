## ✨ Features

- 📚 **Syllabus & Formulas Hub**: Chapter-wise notes, key formulas, shortcut memory tricks, and weightage breakdown.
- ✍️ **Interactive Practice Quiz & Mock Tests**: Topic-wise and sub-exercise unit quiz practice with instant explanations and confetti effects.
- 📋 **Question Bank Data Table**: Interactive table overview of all 227+ practice questions with topic and difficulty filters.
- 🎴 **Formula Flashcards**: Digital flip-cards for rapid formula revision.
- 🧮 **CA Financial & Math Calculator**: Built-in simple and compound interest calculators.
- 🏆 **Gamified Rank & Level System**: Earn XP points and unlock rank titles (Apprentice → AIR 1) as you solve questions.
- 📧 **Direct Email & Feedback**: Send instant feedback or report issues directly to `sahil2412l@gmail.com`.
- ℹ️ **Syllabus Notice Modal**: Exam pattern, marks distribution, and ICAI calculator rules guide.
- ⇥ **Responsive Collapsible Sidebar**: Toggle between full desktop sidebar and compact full-screen view.

- **Bundler & Build Tool**: Vite
- **Deployment**: GitHub Pages (`gh-pages`)

## 🚀 Local Development Setup

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/sahil2412l/CA_Foundation-Course---Paper-3-Quantitative-Aptitude.git
   cd CA_Foundation-Course---Paper-3-Quantitative-Aptitude
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Run Dev Server**:
   ```bash
   npm run dev
   ```

4. **Build Production Bundle**:
   ```bash
   npm run build
   ```

5. **Deploy to GitHub Pages**:
   ```bash
   npm run deploy
   ```
